日本語

  1. 「エルギガンテ」（以下「本ツール」）は、運営者「える」が自分の TikTok アカウントに自分の動画を投稿するための個人用ツールです。
  2. 本ツールが TikTok から受け取る情報は、運営者自身のアカウントの基本情報（open ID・表示名など）と、投稿に必要なアクセストークンだけです。
  3. これらの情報は、運営者のパソコンの中にだけ保存し、投稿のためだけに使います。第三者に渡したり、売ったり、公開したりしません。
  4. 本ツールは、運営者以外の TikTok ユーザーの情報を集めません。視聴者の情報や、他のアカウントの情報も取得しません。
  5. 本ツールは、Cookie・広告・アクセス解析を使いません。
  6. 運営者は、いつでも TikTok の設定から本ツールへの許可を取り消せます。取り消したあとは、保存したアクセストークンを消します。
  7. 本ポリシーは、必要に応じて変更することがあります。変更後のポリシーは、このページに載せた時点から効力を持ちます。
  8. お問い合わせ：erugigante@gmail.com

English

  1. "エルギガンテ" (the "Tool") is a personal tool that its operator, "える", uses to post the operator's own videos to the operator's own TikTok account.
  2. The only information the Tool receives from TikTok is basic information about the operator's own account (such as open ID and display name) and the access token needed to post.
  3. This information is stored only on the operator's own computer and is used only for posting. It is never shared with, sold to, or disclosed to third parties.
  4. The Tool does not collect information about any TikTok user other than the operator, including viewers or other accounts.
  5. The Tool does not use cookies, advertising, or analytics.
  6. The operator can revoke the Tool's access at any time in TikTok's settings. After revocation, the stored access token is deleted.
  7. This Policy may be updated as needed. The updated Policy takes effect when posted on this page.
  8. Contact: erugigante@gmail.com
